# reread スキルの評価

シナリオは `evals.json`、評価用のサンプル資料は `files/hybrid_search.md` にある。
評価にはこのサンプル資料と独立した保存先を使う。実際の書籍・読書記録・個人のメモは使わない。

## ログの匿名化と共有

評価の作業ファイルは `skills/reread-workspace/` に置く。このディレクトリは Git 管理対象外。
評価が終わったら、リポジトリのルートで次を実行する。

```bash
task share-evals
```

[anonymize.py](anonymize.py) が JSON・TXT・Markdown・LOG を匿名化し、共有用の `dist/eval-logs.zip` を作る。
元ファイルを保持したまま、リポジトリの絶対パスを `/workspace/re_read`、個人のホームディレクトリを `/workspace/home` に置き換える。
macOS・Linux・Windows のホームディレクトリ、macOS の一時ディレクトリ、`/tmp`、pytest のユーザー名を含む一時パス、JSON 内のパスを対象にする。再実行すると共有用 ZIP を更新する。
ZIP のファイル名は評価フォルダからの相対パスになり、処理中の出力に元のパスやログ本文は表示しない。

別の評価フォルダや ZIP 保存先を指定するときは次を使う。

```bash
uv run --project skills/reread/tools python skills/reread/evals/anonymize.py <評価フォルダ> <出力.zip>
```

出力先は評価フォルダの外に指定する。文字コードや JSON の形式が不正な場合は処理を中止し、既存の ZIP を保持する。
画像・バイナリ・シンボリックリンクは ZIP に含めず、除外した件数を表示する。スクリーンショットは個別に個人のパスや読書内容を確認してから共有する。

共有するのは作成した ZIP だけにする。本文中の個人情報や秘密情報、ファイル名自体に含まれる名前は、このパス匿名化の対象外なので共有前に確認する。
匿名化した読書記録は共有用のスナップショットであり、再実行時はサンプル資料から作り直す。
アプリが利用する読書記録のパスは、元文書の読み込みと記録の照合に必要なので書き換えない。
