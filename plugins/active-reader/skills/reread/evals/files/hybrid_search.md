# 実践 RAG 入門

## 3.1 BM25

BM25 は古典的な語彙ベースのランキング関数である。クエリ中の各語について、文書内での出現頻度 (TF) を飽和させつつ数え、コーパス全体での希少さ (IDF) で重み付けし、さらに文書長で正規化してスコアを合計する。パラメータ k1 は TF の飽和の速さを、b は文書長正規化の強さを決める。

## 3.2 ベクトル検索

ベクトル検索では、クエリと文書を埋め込みモデルで同じベクトル空間に写し、コサイン類似度などで近いものを探す。語が一致しなくても意味が近ければヒットする一方、型番や固有名詞のような完全一致が重要なクエリには弱い。

## 3.3 Hybrid Search

ハイブリッド検索では、BM25 とベクトル検索の結果を **Reciprocal Rank Fusion (RRF)** で統合する。
RRF は各ランキングでの順位 r に対して 1/(k + r) を足し合わせたものを最終スコアとする。k は通常 60 程度に設定される。

```python
def rrf(rankings, k=60):
    scores = {}
    for ranking in rankings:
        for r, doc in enumerate(ranking, start=1):
            scores[doc] = scores.get(doc, 0) + 1 / (k + r)
    return sorted(scores, key=scores.get, reverse=True)
```

スコアそのものではなく順位だけを使うため、BM25 のスコアとコサイン類似度のようにスケールの異なる値を正規化せずに統合できる。

## 3.4 Re-ranking

統合後の上位候補に対して、クロスエンコーダでクエリと文書のペアを直接評価し、並べ替えることで精度をさらに上げられる。計算コストが高いため、対象は上位数十件に絞るのが一般的である。
