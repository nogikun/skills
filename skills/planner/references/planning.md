# 計画の立て方

目次: 材料を集める / やることにする / 並べる / 打ち合わせ / 例

## 材料を集める

まず `cli.ts brief` の持ち越し候補と繰り返しを見る。そのうえで、ユーザーが示したものを読む。示されずに「探して」「いい感じに」と言われたときだけ、次を順に探す（読むだけ。見つからなければ次へ）。

| 場所 | 見るもの |
|---|---|
| ユーザーの文章 | 箇条書き、締め切り、「今日中」「午前中」などの時間の指定、会議 |
| 指定されたファイル | `- [ ]` の未完了、見出しごとのタスク、議事録の「宿題」「TODO」「次回まで」 |
| 作業フォルダ | `TASKS.md` `TODO*` `NOTES*` `*.md` のチェックボックス（`grep -rn "\- \[ \]" --include=*.md .`） |
| git | `git status`、`git log --since=yesterday --oneline`、作業中のブランチ名 |
| GitHub（`gh` が使えるとき） | `gh issue list --assignee @me`、`gh pr list --author @me`、レビュー待ち `gh pr list --search "review-requested:@me"` |

- 作業フォルダの外や、秘密情報らしいファイル（`.env` など）は読まない。必要ならユーザーに尋ねる。
- 材料が多すぎるときは、締め切りが近いもの・ほかの人を待たせているもの・持ち越しを優先して拾う。

## やることにする

- タイトルは短い名詞句か「動詞＋目的語」（20字以内）。同じ種類の作業は既存の予定と同じタイトルにする（画面の色と月の集計がタイトル単位のため）。詳細はメモに入れる。
- 見積もりは15分単位。迷ったら少し長めに取る。過去の振り返りで同じタイトルの差分（`show` の `actual.diff`）が大きければ、それを足す。
- 2時間を超える集中作業は 60〜90分に分け、間に10〜15分の休憩を入れる。
- 会議・繰り返し予定・ユーザーが時刻を指定したものは「固定」として先に置く。

## 並べる

1. 固定の予定を置く。
2. 締め切りが今日のもの、ほかの人を待たせているもの（レビュー、返信）を早めに置く。
3. 頭を使う作業は、ユーザーの指定がなければ午前など空き時間の長い所に置く。細かい作業（メール、事務）は会議の前後や夕方にまとめる。
4. 昼食（指定がなければ PM 12:00〜1:00 前後）と休憩を入れる。
5. 合計が空き時間の 8〜9割に収まるようにし、残りは余白にする。収まらない分は「今日はやらないこと」に回し、持ち越し先（明日・今週中）の案を添える。
6. 今日の場合、今の時刻より前には置かない（`brief` の空き時間を使う）。

## 打ち合わせ

案はこの形で出す。

```
今日やり切ること: 〇〇の初版を出す

| 時刻 | 予定 | 見積もり | 理由 |
|---|---|---|---|
| AM 9:30〜10:30 | 設計レビュー | 60分 | 10:30 のレビュー依頼に間に合わせる |
| … | … | … | … |

今日はやらないこと: △△（明日の午前に回す案）
確かめたいこと: □□の締め切りは今日ですか？
```

- 質問は答えで案が変わるものだけ、一度に2〜3個まで。
- ユーザーの返事で直したら、変えた所だけを示して再確認する。
- 合意したら SKILL.md の「予定の書き込み」の手順で書く。

## 例

入力: 「今日は 14 時から定例。午前中に API の設計をまとめたい。あとレビューが2件たまってる」（今は AM 9:10、空き AM 9:15〜PM 6:00）

案:

| 時刻 | 予定 | 見積もり | 理由 |
|---|---|---|---|
| AM 9:15〜9:45 | コードレビュー | 30分 | 2件のうち小さい方。待たせている人がいる |
| AM 9:45〜11:15 | API 設計 | 90分 | 午前中にまとめたいとのこと |
| AM 11:15〜11:30 | 休憩 | 15分 | |
| AM 11:30〜PM 12:00 | API 設計 | 30分 | 設計の仕上げ |
| PM 12:00〜1:00 | 昼食 | 60分 | |
| PM 1:00〜1:45 | コードレビュー | 45分 | 残りの1件 |
| PM 2:00〜3:00 | 定例 | 60分 | 固定 |

確かめたいこと: 定例は 1 時間ですか？ API 設計は午前中に「まとめる」までで、共有は午後でよいですか？
